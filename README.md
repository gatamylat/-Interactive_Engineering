# Интерактивный инженерный конструктор

Личная PWA для подготовки задания. На выходе получается один Markdown-пакет для Codex, Kimi, Гермеса или другого исполнителя.

1. Запишите задачу и ожидаемый результат.
2. Добавьте материалы из библиотеки вручную или выберите Claude либо DeepSeek и нажмите «Составить план».
3. Отредактируйте шаги и проверьте материалы. У каждого шага есть действие, результат и критерий проверки.
4. Скопируйте пакет или скачайте его. Удачный план можно сохранить в «Рецептах».

## Библиотека

В карточке можно хранить текст, фрагмент кода или ссылку на оригинал. Добавляйте только материалы, которые готовы передать выбранному исполнителю. При построении плана модель получает задачу и краткие выдержки из кандидатов. При экспорте выбранные материалы входят в пакет. Подтверждённые правила поведения хранятся в рубрике «Ожидания» вместе со способом проверки.

## Работа на двух устройствах

В настройках создайте и подключите личный код, затем введите тот же код на втором устройстве. Код открывает отдельную библиотеку Конструктора. Для переноса рабочего плана нажмите «Сохранить сборку», дождитесь статуса «Синхронизировано» и откройте сборку из «Рецептов» на втором устройстве. Черновик между сохранениями хранится на текущем устройстве. Ключи моделей задаются отдельно на каждом устройстве.

Локальная копия хранится в IndexedDB. Для синхронизации используется существующий Firebase по схеме AI Пульта, с отдельным путём и шифрованием записей по личному коду. Если соединение недоступно, работают локальная библиотека, ручной план и экспорт. Если материалы были добавлены до подключения кода, их можно найти, отключив код и вернувшись в локальную библиотеку.

## Запуск

Статическое приложение. Для локального запуска выполните `python3 -m http.server 8000` из корня репозитория и откройте `http://localhost:8000`. Для публикации GitHub Pages используется корень ветки `main`. На iPhone приложение можно открыть в Safari и добавить на экран «Домой».

Работа с кодом, запуск тестов и публикация проектов выполняются во внешней среде. В этой версии передача пакета выполняется вручную.
