## Что делает приложение

Браузерная PWA для подготовки и выполнения инженерных задач с Claude или DeepSeek. Вы описываете задачу, Конструктор составляет план и выполняет его по шагам. Для работы с моделью нужен её API-ключ в настройках.

1. Введите задачу, выберите формат результата и нажмите **«Составить план»**.
2. Нажмите **«Согласовать план»**, затем **«Выполнить план»**. «Рабочий план» и «Кирпичики» можно раскрыть, если хотите что-то изменить.
3. По завершении нажмите **«Скачать файлы»**. Журнал можно скопировать отдельной кнопкой. Если для плана подготовлены сценарии приёмки, их можно проверить или пропустить приёмку.

Доступны форматы «Один HTML», «PWA (несколько файлов)» и «Документ Markdown». В режиме «Один HTML» приложение умеет собрать сохранённые JS/CSS-модули в один `index.html`. Отдельно можно собрать и экспортировать Markdown-задание для внешнего исполнителя, например Codex, Kimi или Гермеса.

## Данные и запуск

Черновик, ключи API и архив запусков хранятся на устройстве. Библиотека хранится в IndexedDB и может синхронизироваться по личному коду. Чтобы перенести план на другое устройство, сохраните сборку и откройте её там из «Рецептов» после синхронизации.

Для локального запуска выполните `python3 -m http.server 8000` из корня репозитория и откройте `http://localhost:8000`. GitHub Pages публикует приложение из ветки `main`.
